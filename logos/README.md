# Tempore logos with the name

The mark of [`web/logo/`](../web/logo/) with the name *Tempore*, set in Inter
SemiBold (SIL Open Font License) and converted to outlines, so that no font is
needed to render them.

- `tempore-wordmark.*`: the mark beside the name.
- `tempore-wordmark-stacked.*`: the mark above the name.

Each comes in three versions: for light backgrounds (`.svg`, with `.pdf` and
`.png` exports), for dark backgrounds (`-dark`, likewise), and in one colour
(`-mono.svg`, drawn in `currentColor`). The PNG exports are 2780 px (beside)
and 1600 px (stacked) wide, with transparent backgrounds.

Colours as in [`web/logo/README.md`](../web/logo/README.md): time blue
`#3298dc`, ink `#24292e`, ring track `#cfe6f8`; on dark backgrounds, paper
`#fbfaf7` and track `#4b5563`.
